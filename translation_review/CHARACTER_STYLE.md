# 오버필드 한국어 번역 기준

대상: Table 1, 7, 17, 20, 46, 63. 기준 원문은 실제 번들의 `String_Japanese`이며, 편집용 `translations.json`의 `ja`와 다르면 번들을 우선한다. `source_overrides.json`에 이번에 다시 동기화한 원문을 기록했다. 일부 원문은 중국어이므로 언어를 확인한다. 아래 성격은 수록 대사의 말투·행동에서 확인한 번역 지침이며 공식 설정집의 인물 소개가 아니다. 나이·성별·관계·과거를 임의로 보충하지 않는다.

## 공통 규칙

- 의미와 조건을 먼저 보존하고 자연스럽게 다듬는다. 원문에 없는 농담·욕설·감정·능력·친밀감을 추가하지 않는다.
- 같은 인물도 상대에 따라 존댓말을 바꿀 수 있다. 특히 선배·스승·손님에게 쓰는 경어를 일괄 반말로 바꾸지 않는다.
- Table 46의 화자는 `speaker_ja`와 해당 행의 일본어 화자명 필드를 함께 확인한다. 빈 화자는 추정 배정하지 않는다. `?`, `??`, 인물명 뒤 `?`는 정체가 밝혀지기 전의 표기이므로 합치지 않는다.
- 화자 이름과 본문 이름, 캐릭터/장비 이름을 함께 맞춘다. 인명은 과일 등의 일반 명사로 직역하지 않는다. 별칭과 본명은 대사에서 구별한다.
- Table 1 설명은 간결한 설명체, 인용문은 원문 화자의 경어를 유지한다. Table 7·17은 `~한다`, Table 63 규칙은 `~하세요/~합니다`. Table 20은 편지·기사·공지·일기에 맞는 문체를 적용한다.
- 수치·단위·범위·조건·주체를 보존한다. `未満`은 미만, `以下`는 이하, `以上`은 이상. AP의 고정 수치를 %로 바꾸지 않는다. `最大HPの`는 최대 생명력 기준임을 명시한다. 개인 효과를 팀 전체 효과로 확대하지 않는다.
- `ブレイク`(브레이크), `ノックバック`(밀쳐내기), `打ち上げ`(공중에 띄우기)는 서로 다른 표현이다. 같은 효과라고 추정하지 않는다.
- `{0}`, `{0:P1}`, `{|}`, `$...$`, `<color=...>`, `<br>`, 태그와 이스케이프 시퀀스 등 실행에 쓰이는 문자열을 번역하지 않는다. 원문 자체의 미완성 `技能描述...`는 임의 능력으로 채우지 않고 별도 검토 목록에 남긴다.
- 번역 완료와 검토 완료를 구분한다. 자동으로 이름만 통일한 행을 문장 전체를 검토한 것으로 계산하지 않는다.

## 검토의 증거와 재사용

`speaker_evidence.md`에는 원문 화자별 실제 대사 UID와 일본어를 보관한다. `changes.json`에는 수정 전후와 사유를 남긴다. `review_report.md`의 직접 윤문·정형 설명 교정·인명/용어 통일 수치를 구분해 읽는다. 미래 작업도 이 기준을 먼저 읽고, 기존 번역이 원문과 충돌하면 기준에 맞춰 고친다.

## Table 20의 서신·기사 화자

- 비나 → 메렌: 오랜 친구에게 연구 진전을 전하는 편지. 격의 없는 해체, 다정함과 연구 의욕을 살린다. 메렌의 여행 이유를 지쳤기 때문이라고 단정하지 않는다.
- 메이 → 비: 친한 친구에게 쉬고 싶은 마음과 책·글쓰기를 이야기하는 해체. 비가 비나의 별칭일 가능성이 있어도 수신인 원문은 그대로 보존한다. A주를 아리조나로 확정하지 않는다.
- 리사 → 릭: 아내가 남편에게 탐색 참여를 알리는 편지. 다정한 해요체, RIUQ·F11·연월 표기를 보존한다.
- 병 편지의 익명 작성자: 처음 연락하는 상대에게 정중한 해요체. 친구가 되고 싶다는 제안을 이미 친구가 될 것이라는 확신으로 바꾸지 않는다.
- 고백 편지의 익명 작성자: 수줍고 정중한 해요체. 원문이 밝히지 않은 작성자의 성별·관계를 추가하지 않는다.
- 기관지·학술지 기자: 서술부는 객관적인 문어체. 인용·인터뷰는 별도의 화자 말투로 번역한다. 젊은 과학자들을 여성 과학자로 좁히지 않는다.

## 스킬·효과 참조

스킬 제목과 설명 속 참조를 같이 수정한다. 재봉사 돌진, 가위 급습, 체포의 순간, 시간의 단도, 시곗바늘 부메랑 등 기존 UI 이름을 유지한다. 원문과 크게 어긋난 이름은 점보 커터·경로 표식 등으로 고쳤다. 실제 대응표는 `apply_review.py`의 SKILLS를 기준으로 한다. 동일한 표현이 일반 명사로 쓰인 경우까지 바꾸지 않는다.

기관·간행물은 로타 연구소, 프네우마회, 프네우마 역사연구회, 『별 물질』, 『프네우마이즘』으로 통일한다. 인리움의 일본어 표기는 イン元素 및 インリウム을 함께 참고한다.
