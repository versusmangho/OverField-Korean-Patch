# 🌸 오버필드 (OverField) 고품질 한국어화 패치 & 전용 런처

스팀(Steam) 게임 **오버필드 (OverField)**의 비공식 고품질 한국어 패치 및 라이브 서비스 핫픽스 대응 자동 런처 프로젝트입니다.

---

## 🚀 빠른 시작 (런처 사용 방법 - 권장)

1. **[Releases](../../releases)** 탭에서 최신 버전의 **`OverFieldLauncher.exe`** (또는 `OverField_Korean_Patch_v1.0.zip`)를 다운로드합니다.
2. 다운로드한 **`OverFieldLauncher.exe`**를 실행합니다.
   * 스팀 게임 설치 폴더가 자동으로 감지됩니다.
   * 백그라운드에서 YooAsset 캐시 및 핫픽스 여부를 1초 만에 자동 점검합니다.
3. **[🎮 게임 시작 (GAME START)]** 버튼을 누르면 스팀을 통해 한국어가 적용된 오버필드가 바로 실행됩니다!

> 💡 **핫픽스 자동 극복 시스템**: 게임사에서 점검이나 핫픽스를 배포하여 캐시가 초기화되더라도, 런처를 켜면 자동으로 패치를 재주입하고 CRC32 무결성을 동기화하므로 항상 안전하게 한글로 플레이하실 수 있습니다.

---

## 🛠️ 수동 덮어쓰기 설치 방법

1. 게임을 완전히 종료합니다.
2. `OverField_Korean_Patch_v1.0.zip`의 압축을 푼 뒤 나오는 `launcher_Data` 폴더를 게임 설치 경로에 덮어씌웁니다.
   * 기본 경로: `C:\Program Files (x86)\Steam\steamapps\common\OverField`
3. 게임을 실행합니다.

## 📝 주요 패치 내역

* **스토리 & 퀘스트 전면 고품질 윤문**:
  * 프롤로그 및 1장 메인 스토리, 탐색 퀘스트 전면 자연스러운 캐릭터 구어체로 재번역 (시, 페이, 팡틴 등 캐릭터성 보존)
* **전투 스킬 & 장비 효과 (Table 7 & Table 17)**:
  * 캐릭터 전투 스킬, 패시브, 돌파 효과, 세트 옵션의 중국어 잔재 전면 교정
  * 미번역 상태였던 캐릭터 돌파/아카이브 특성(레몬, 나오키 등) 100% 한국어화
* **미니게임 & 오브젝트 (Table 63 & Table 20)**:
  * 풍선 터뜨리기, 발판 퍼즐, 작살전 미니게임 룰 및 카운터 완전 번역
  * 인게임 편지 및 상세 정보 번역 교정
* **음성 자막 결함 & 화자 이름 100% 수리**:
  * 일본어 분할 타이밍 음성으로 인해 중간에 잘리던 자막 슬롯 결합 복구 (83개소)
  * 인게임에 중국어로 노출되던 화자 이름(`引导员 菲` ➔ `가이드 페이`, `芳汀` ➔ `팡틴` 등 149개소) 전면 교정

## ⚙️ 스팀(Steam) 라이브러리 연동 방법 (선택 사항)

스팀 라이브러리에서 [플레이] 버튼을 눌렀을 때도 런처가 먼저 뜨게 하려면:
1. 스팀 라이브러리에서 **OverField** 우클릭 ➔ **속성** 클릭
2. **일반** 탭의 **시작 옵션**에 다음 명령어를 입력합니다:
   ```text
   "C:\Program Files (x86)\Steam\steamapps\common\OverField\OverFieldLauncher.exe" %command%
   ```
